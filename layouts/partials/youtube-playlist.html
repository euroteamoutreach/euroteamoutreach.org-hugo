{{- /* youtube-playlist — a responsive embed of a whole YouTube playlist. Hugo's built-in youtube shortcode takes a VIDEO ID only: given a playlist ID it builds /embed/, which does not play (checked on 0.167). The playlist form is /embed/videoseries?list=, so this wraps that instead. docs/prd/06-shortcodes.md anticipated the wrap. youtube-nocookie.com is YouTube's privacy-enhanced domain: no tracking cookies until the visitor presses play. loading="lazy" keeps the player's heavy script off the network until the embed nears the viewport. Params (dict): list (required) the playlist ID, e.g. "PLwBim7LWPkX…" title (required) accessible name for the iframe, e.g. "UGO 2025" */ -}} {{- if not .list -}} {{- errorf "youtube-playlist: 'list' is required" -}} {{- end -}} {{- if not .title -}} {{- errorf "youtube-playlist: 'title' is required for %q" .list -}} {{- end -}}
