{{- /* illustration — an SVG illustration from assets/img//. Floated right beside the paragraphs that follow it, or stacked and centred on phones. With wide="true" it is a figure of its own across the column, for a diagram too wide to sit beside text. The figure carries the class "illustration" so a page with room to its right can hang it in the margin (layouts/jesus.html). An , not inlined: the artwork's lettering is drawn as paths, so the alt text carries the words. Its width and height come from the SVG's viewBox, so the space is reserved before the lazy load. Params: src (required) file basename alt (required) what the illustration says width (floated only) its width beside the text, e.g. "10rem"; phones get three quarters of it, and a caption may run wider than the art wide "true" for the full-column placement An optional caption goes between the tags (Markdown). */ -}} {{- $src := .Get "src" -}} {{- $alt := .Get "alt" -}} {{- if or (not $src) (not $alt) -}} {{- errorf "illustration: 'src' and 'alt' are required (%s)" .Position -}} {{- end -}} {{- $path := printf "img/%s/%s.svg" .Page.Section $src -}} {{- $img := resources.Get $path -}} {{- if not $img -}} {{- errorf "illustration: no assets/%s (%s)" $path .Position -}} {{- end -}} {{- $box := index (findRESubmatch `viewBox="[\d.]+ [\d.]+ ([\d.]+) ([\d.]+)"` $img.Content 1) 0 -}} {{- $img = $img | minify | fingerprint -}} {{- $wide := eq (.Get "wide") "true" -}} {{- $width := .Get "width" -}} {{- if and (not $wide) (not $width) -}} {{- errorf "illustration: a floated illustration needs 'width' (%s)" .Position -}} {{- end -}} {{- $figure := "illustration mx-auto mb-6 w-fit max-w-full md:float-right md:clear-right md:mt-1 md:mb-4 md:ml-8 md:w-(--fig-w) lg:ml-12" -}} {{- $art := "mx-auto w-[calc(var(--fig-w)*0.75)] md:w-full" -}} {{- if $wide -}} {{- $figure = "my-8 md:my-10" -}} {{- $art = "mx-auto w-full max-w-xl" -}} {{- end -}}
